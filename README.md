# Флорариум

`Флорариум` — проект информационной веб-системы для подбора и заказа декоративных растений. Покупатель указывает условия помещения и требования к уходу, получает персональную подборку растений и может оформить заказ через корзину.

## Основные возможности

- просмотр каталога и карточек растений;
- заполнение анкеты об условиях помещения;
- персональный подбор растений с пояснением;
- добавление растений в корзину и оформление заказа;
- обработка заказов менеджером.
- управление каталогом и параметрами ухода;
- просмотр сводной статистики владельцем магазина.

## Пользователи

Гость, покупатель, менеджер магазина, контент-менеджер, администратор и владелец магазина.
