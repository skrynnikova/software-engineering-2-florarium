# Запрос на изменение

| Поле | Содержание |
|---|---|
| Название | Напоминания о поливе купленных растений |
| Причина | Покупатель может забыть о поливе и потерять растение, хотя система уже знает его требования к уходу |
| Какие требования добавятся | Покупатель может включить напоминания для купленного растения; система отправляет напоминание в день полива |
| Что нужно изменить | Модуль уведомлений; классы PlantCareSchedule и Reminder; класс Notification; сценарий после покупки; два тест-кейса — отправка напоминания и отключение напоминаний |
| Новая версия | 1.2.0 — добавляется новая возможность |
